# Home Assistant notification badges

Coloured badge images for Home Assistant mobile notifications. Referenced from
automations via the `image` field of `notify.mobile_app_*`.

These exist because per-notification `color` and custom icons **do not render on
Android 13+**, and on Android 16 the shade icon is dropped entirely. An image
attachment is the only reliable way to get a coloured, instantly-recognisable alert.

See `analysis/ANDROID_NOTIFICATION_STYLING.md` in the `ha-energy-analysis` repo for the
full evidence.

## Usage

```yaml
action: notify.mobile_app_oneplus15
data:
  title: "House Battery Low!"
  message: "..."
  data:
    channel: "Battery Alerts"
    color: "#F44336"
    notification_icon: "mdi:battery-alert"
    image: "https://cdn.jsdelivr.net/gh/stevelea/ha-notify-badges@main/battery_critical.png"
```

## Images

| File | Use |
|---|---|
| `garage_open.png` | Garage door left open |
| `garage_closed.png` | Garage door closed |
| `battery_critical.png` | Battery below minimum SOC |
| `battery_charged.png` | Battery reached target SOC |
| `ev_charging.png` | EV charging in progress |
| `grid_charge.png` | Cheap-rate grid charging |
| `pool_needs_charge.png` | Pool robot battery low |
| `pool_finished.png` | Pool robot finished cleaning |
| `system_fault.png` | Connection or copy error |
| `car_sentinel.png` | Vehicle sentinel alert |
| `weekly_summary.png` | Weekly energy summary |

All images are 1024x512 PNG. Generated by `assets/notification-badges/make_badges.py`.
